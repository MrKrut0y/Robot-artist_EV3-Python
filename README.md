# [Robot Artist EV3: Программный комплекс для управления роботом-художником](https://github.com/MrKrut0y/Robot-artist_EV3-Python.git)

**Robot Artist EV3** — десктопное приложение с GUI для генерации траекторий робота-художника на базе **LEGO Mindstorms EV3**. Преобразует ручные наброски и растровые изображения в координаты для V-образного подвеса с двумя нитями.

## Основные возможности

*   **Векторный редактор** — ручное создание траекторий на координатной сетке с поддержкой сегментации (поднятие/опускание пера).
*   **Инструменты редактирования** — интерактивное перемещение узлов (drag-and-drop) и удаление точек.
*   **Загрузка координат** — импорт траекторий из G-кода или файлов координат робота для последующего редактирования.
*   **Конвертер G-кода** — преобразование стандартных G-code файлов (*.gcode, *.nc, *.txt, *.tap) в формат робота.
*   **Компьютерное зрение (OpenCV)** — загрузка изображений и автоматическое выделение контуров.
*   **Оптимизация траектории** — упрощение векторов алгоритмом Дугласа-Пекера.
*   **Контурный экстрактор** — выделение контуров методами Канни и пороговой обработки.
*   **Настройка параметров** — скорость рисования, скорость перемещения, масштаб.
*   **Экспорт** — генерация файла `pict_coord.rtf` и `config.cfg` для EV3.
*   **Удалённое управление** — загрузка файлов и запуск робота по Bluetooth (SSH).

## Подготовка и запуск

### 1. Подготовка контроллера EV3

1.  [Инструкция по сборке робота](https://github.com/MrKrut0y/Robot-artist_EV3-Python/tree/main/dop/Инструкция%20по%20сборке%20робота)
2.  Скачайте прошивку [**ev3dev**](https://www.ev3dev.org/) (рекомендуется) или [**Pybricks MicroPython**](https://education.lego.com/en-us/product-resources/mindstorms-ev3/teacher-resources/python-for-ev3/) (альтернативная прошивка)
3.  Запишите образ на microSD карту (например, через [Etcher](https://etcher.balena.io/))
4.  Вставьте карту в выключенный EV3 и включите его. Дождитесь загрузки

> **Примечание:** Данный проект разработан для прошивки **ev3dev** и протестирован на **Pybricks MicroPython**. Код совместим с обеими прошивками.

### 2. Запуск GUI на ПК

```
python gui_python.py
```

### 3. Загрузка программы на робота

Есть **два способа** передать файлы на EV3:

#### Способ A: По USB-кабелю (проводной)

1.  Подключите EV3 к компьютеру mini-USB кабелем
2.  Откройте проект в VS Code с расширением **LEGO MINDSTORMS EV3**
3.  Подключитесь к роботу через `EV3 Device Browser`
4.  Скопируйте файлы `main.py`, `config.cfg` и `pict_coord.rtf` в папку проекта на роботе
5.  Нажмите кнопку загрузки
6.  Запустите `main.py` через файловый менеджер на блоке EV3

#### Способ B: По Bluetooth (беспроводной)

1.  Свяжите EV3 с ПК по Bluetooth (Personal Area Network)
2.  Убедитесь, что робот доступен по адресу `ev3dev.local`, на экране робота появился IP-адрес и в настройках подключения написан статус `Connected`
3.  В приложении нажмите **«Запустить на EV3»** — файлы загрузятся автоматически через SSH
4.  Робот начнет рисование сразу после передачи файлов

> Приложение само проверяет наличие файлов `main.py` и `pict_coord.rtf` в папке `ev3-main/`, загружает их на робота и запускает выполнение.

## Математическая база

### [Инверсная кинематика](https://github.com/MrKrut0y/Robot-artist_EV3-Python/blob/main/dop/кинематич.схема.pdf)

Расчет длин нитей для V-образного подвеса:

$$L_1 = \sqrt{(B + x)^2 + (H - y)^2}$$
$$L_2 = \sqrt{(B - x)^2 + (H - y)^2}$$

Где $B$ — расстояние от центра до мотора, $H$ — высота подвеса.

### [Преобразование координат](https://github.com/MrKrut0y/Robot-artist_EV3-Python/blob/main/dop/Пересчет%20координат.pdf)

1.  **Масштабирование**: координаты умножаются на $0.833$ и глобальный множитель `SCALE` (по умолчанию $1.3$)
2.  **Смещение**: к $y$ добавляется $+280$ мм (безопасная зона ниже двигателей)

### Перевод длины нити в угол мотора

*   **Коэффициент**: $18.48$ градусов на 1 мм длины нити
*   **Расчет**: $\Delta \alpha = (660 - L) \times 18.48$

## Формат файла координат (`pict_coord.rtf`)

1.  **Заголовок** — первая строка: общее количество точек
2.  **Координаты** — каждая точка: строка $X$, строка $Y$
3.  **Подъем пера** — если $X > 500$, вычитается $1000$ и робот перемещается с поднятым маркером

### Загрузка координат

Приложение поддерживает загрузку траекторий из внешних файлов:

*   **G-код** (*.gcode, *.nc, *.txt, *.tap) — стандартный формат ЧПУ. Автоматически конвертируется в формат робота
*   **Координаты робота** (*.rtf, *.txt) — собственный формат приложения

Для загрузки:
1.  Перейдите на вкладку «Ручное рисование»
2.  Нажмите кнопку **«Загрузить координаты»**
3.  Выберите тип файла: «G-код» или «Координаты робота»
4.  Выберите файл
5.  Координаты отобразятся на холсте и станут доступны для редактирования
