# [Robot Artist EV3: Программный комплекс для управления роботом-художником](https://github.com/MrKrut0y/Robot-artist_EV3-Python.git)

**Robot Artist EV3** — это десктопное приложение с графическим интерфейсом, предназначенное для генерации, редактирования и подготовки траекторий движения робота-художника на базе контроллера **LEGO Mindstorms EV3**. Приложение позволяет преобразовывать как ручные наброски, так и растровые изображения в формат координат, понятный роботу.

## Основные возможности

*   **Векторный редактор**: ручное создание траекторий на координатной сетке с поддержкой сегментации (поднятие/опускание пера).
*   **Инструменты редактирования**: интерактивное перемещение узлов (Drag-and-drop) и удаление ошибочных точек.
*   **Компьютерное зрение (OpenCV)**: загрузка изображений и автоматическое выделение контуров.
*   **Оптимизация траектории**: упрощение векторов с помощью алгоритма Дугласа-Пекера для уменьшения количества команд.
*   **Экспорт**: генерация файла координат `pict_coord.rtf` в специфическом формате для микроконтроллера EV3.

## [Подготовка и запуск робота](https://github.com/MrKrut0y/Robot-artist_EV3-Python/blob/main/dop/getting-started-with-micropython-v2_enus.pdf)

Процесс подготовки разделен на два этапа: прошивка системы и загрузка рабочей программы.

### 1. Подготовка контроллера EV3

1.  [Иструкция по сборке робота](https://github.com/MrKrut0y/Robot-artist_EV3-Python/tree/main/dop/Инструкция%20по%20сборке%20робота)
2.  Скачайте образ прошивки [**Pybricks MicroPython**](https://education.lego.com/en-us/product-resources/mindstorms-ev3/teacher-resources/python-for-ev3/).
3.  Запишите образ на microSD карту с помощью утилиты (например, Etcher).
4.  Вставьте карту в выключенный EV3 и включите его. Дождитесь завершения загрузки.

### 2. Загрузка программы и данных

1.  Подключите EV3 к компьютеру с помощью mini-USB кабеля.
2.  Откройте проект в VS Code. Убедитесь, что установлено расширение **LEGO MINDSTORMS EV3**.
3.  Подключитесь к роботу через панель расширения (раздел `EV3 Device Browser`).
4.  Скопируйте в папку проекта следующие файлы:
    *   `main.py` (управляющий скрипт робота).
    *   `pict_coord.rtf` (файл, сгенерированный данным приложением).
5.  Нажмите кнопку загрузки для передачи файлов на робота.
6.  Запустите выполнение через файловый менеджер на самом блоке EV3, выбрав файл `main.py`.

## Технические характеристики

### Конфигурация портов

*   **Port A**: Большой мотор (Левый привод нити)
*   **Port B**: Большой мотор (Правый привод нити)
*   **Port C**: Средний мотор (Механизм подъема маркера)

### [Математическая база](https://github.com/MrKrut0y/Robot-artist_EV3-Python/blob/main/dop/кинематич.схема.pdf)

Программа рассчитывает положение пера на основе инверсной кинематики для V-образного подвеса:

*   **Расчет длин нитей**:
    $$L_1 = \sqrt{(B + x)^2 + (H - y)^2}$$
    $$L_2 = \sqrt{(B - x)^2 + (H - y)^2}$$
    Где $B$ — расстояние от центра до мотора, $H$ — высота подвеса.

*   **Перевод в углы моторов**: Используется коэффициент **18.48** (градусов на 1 мм пути), рассчитанный исходя из диаметра барабана 6.2 мм.

### [Преобразование координат](https://github.com/MrKrut0y/Robot-artist_EV3-Python/blob/main/dop/Пересчет%20координат.pdf)

Для корректного отображения и учета физических ограничений робота применяется масштабирование и смещение:

1.  **Масштабирование**: Входные координаты умножаются на коэффициент $0.833$ (соотношение рабочего поля к программному) и глобальный множитель `SCALE` (по умолчанию $1.3$).
2.  **Смещение**: К координате $y$ добавляется константа $+280$ мм, что определяет "безопасную зону" начала рисования ниже уровня двигателей.

### Перевод длины нити в угол двигателя

Контроллер оперирует не миллиметрами, а градусами поворота вала.

*   **Барабан**: Диаметр вала составляет примерно $20$ мм.
*   **Коэффициент**: Экспериментально установленное значение **18.48** градуса на 1 мм длины нити.
*   **Расчет**: Угол поворота $\alpha$ вычисляется как разница между максимальной длиной нити ($660$ мм) и текущей расчетной длиной, умноженная на коэффициент:
    $$\Delta \alpha = (660 - L) \times 18.48$$

## Формат файла координат (`pict_coord.rtf`)

Программа использует текстовый формат обмена данными. Структура файла:

1.  **Заголовок**: Первая строка содержит общее количество точек в файле.
2.  **Координатный блок**: Каждая точка описывается двумя строками (сначала $X$, затем $Y$).
3.  **Управление пером**:
    *   Если значение $X > 500$, это интерпретируется как команда "поднять перо". Программа вычитает $1000$ из значения, чтобы получить реальную координату $X$, перемещает робота с поднятым маркером и опускает его в целевой точке.
    *   Значения $X \leq 500$ считаются обычными точками для рисования линии.

## Управление в редакторе

*   **ЛКМ**: Добавление точки в режиме рисования / Выбор и перенос точки в режиме редактирования.
*   **ПКМ**: Удаление выбранного узла.
*   **Space (Пробел)**: Создание разрыва в линии (команда роботу поднять перо).
*   **X**: Удаление последней точки.
