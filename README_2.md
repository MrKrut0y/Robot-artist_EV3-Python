# Робот-художник EV3 - Структура проекта

## Описание

Программа для управления роботом-художником на базе LEGO Mindstorms EV3. Позволяет создавать траектории рисования вручную или автоматически из изображений.

## Структура проекта

```
Robot-artist_EV3-Python-main/
├── gui_python.py              # Главный файл запуска приложения
├── ui_main.py                 # Сгенерированный UI главного окна
├── ui_settings.py             # Сгенерированный UI окна настроек
├── main.py                    # Альтернативная точка входа
├── ev3-main/
│   └── main.py               # Программа для EV3 (загружается на робота)
├── gui_modules/              # Модули графического интерфейса
│   ├── __init__.py
│   ├── config.py             # Управление конфигурацией робота
│   ├── models.py             # Базовые модели данных (Point)
│   ├── dialogs.py            # Диалоговые окна (настройки)
│   ├── canvas_draw.py        # Холст для ручного рисования (вкладка 1)
│   ├── canvas_image.py       # Холст для работы с изображениями (вкладка 2)
│   ├── canvas_contour.py     # Контурный экстрактор (вкладка 3)
│   └── main_window.py        # Главное окно приложения
├── config.cfg                # Файл конфигурации для EV3
└── pict_coord.rtf           # Файл с координатами для робота
```

## Модули

### config.py
Управляет глобальными параметрами робота:
- `SCALE` - масштаб изображения (по умолчанию 1.3)
- `DRAW_SPEED` - скорость рисования (1-1000)
- `TRAVEL_SPEED` - скорость перемещения (1-1000)
- `PEN_UP_CODE` - код для подъема пера (1000)

Функции:
- `load_config()` - загрузка конфигурации из файла
- `save_config()` - сохранение конфигурации в файл
- `get_config()` - получение текущих значений

### models.py
Содержит класс `Point` для работы с координатами:
- `to_canvas_coords()` - преобразование координат робота в координаты холста
- `from_canvas_coords()` - обратное преобразование

### dialogs.py
Диалоговое окно настроек робота `SettingsDialog`:
- Настройка скорости движения (TRAVEL_SPEED)
- Настройка скорости рисования (DRAW_SPEED)
- Настройка масштаба (SCALE)
- Сохранение в config.cfg для использования на EV3

### canvas_draw.py
Холст для ручного рисования `DrawCanvas`:
- Режимы: рисование и редактирование
- Добавление точек левой кнопкой мыши
- Удаление точек правой кнопкой мыши
- Создание новых сегментов (пробел)
- Перемещение точек в режиме редактирования

### canvas_image.py
Холст для работы с изображениями `ImageCanvas`:
- Загрузка изображений
- Автоматическое распознавание контуров
- Упрощение контуров (алгоритм Ramer-Douglas-Peucker)
- Преобразование контуров в координаты робота

### canvas_contour.py
Контурный экстрактор `ContourExtractor`:
- Метод Канни (Canny edge detection)
- Пороговая обработка (threshold)
- Размытие по Гауссу
- Сохранение результатов в различных форматах

### main_window.py
Главное окно приложения `MainWindow`:
- Управление тремя вкладками
- Сохранение координат в pict_coord.rtf
- Интеграция всех модулей

## Формат файлов

### config.cfg
```
SCALE=1.3
DRAW_SPEED=500
TRAVEL_SPEED=500
```

### pict_coord.rtf
```
<количество_точек>
<x1>
<y1>
<x2>
<y2>
...
```

Координаты X первой точки каждого сегмента увеличены на 1000 (PEN_UP_CODE), чтобы робот знал, что нужно поднять перо перед перемещением.

## Запуск

```bash
python gui_python.py
```

## Требования

- Python 3.6+
- PyQt5
- OpenCV (cv2)
- NumPy

## Использование

1. **Вкладка 1 - Ручное рисование:**
   - ЛКМ - добавить точку
   - ПКМ - удалить точку
   - Пробел - новый сегмент
   - Кнопка "Редактировать" - режим перемещения точек

2. **Вкладка 2 - Изображения:**
   - Загрузить изображение
   - Автоматическое распознавание контуров
   - Упростить контуры ползунком
   - Сохранить координаты

3. **Вкладка 3 - Контурный экстрактор:**
   - Загрузить изображение
   - Выбрать метод (Канни/Порог)
   - Настроить параметры
   - Предпросмотр и сохранение

4. **Настройки робота:**
   - Кнопка "Настройки робота"
   - Установить скорости и масштаб
   - Сохранить в config.cfg

5. **Передача на EV3:**
   - Сохранить координаты (pict_coord.rtf)
   - Сохранить настройки (config.cfg)
   - Скопировать оба файла на EV3
   - Запустить ev3-main/main.py на роботе

## Координатная система

Рабочая область робота: 480×360 мм
- Центр: (0, 0)
- X: от -240 до +240
- Y: от -180 до +180
