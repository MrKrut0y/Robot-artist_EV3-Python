# Robot Artist EV3

## Описание программы

Robot Artist EV3 — это программа с графическим интерфейсом для подготовки траекторий движения робота-художника на базе LEGO EV3.

Программа позволяет:

* вручную рисовать линии на координатной сетке
* редактировать точки траектории
* загружать изображения
* автоматически распознавать контуры изображения
* преобразовывать контуры в координаты
* сохранять координаты для робота
* запускать программу на EV3

Программа разработана для управления роботом, который рисует на вертикальной поверхности, перемещая перо с помощью двух нитей.

# Подключение EV3

Перед запуском программы робот LEGO EV3 должен быть подключён к компьютеру.

## Требования

- Установленная прошивка EV3 MicroPython
- Подключение EV3 к компьютеру через mini-USB кабель
- Установлен Python и библиотека pybricksdev

## Подключение выполняется следующим образом

1. Подготовить microSD карту с прошивкой EV3 MicroPython
2. Вставить microSD карту в EV3
3. Включить EV3
4. Подключить EV3 к компьютеру через mini-USB кабель
5. Дождаться пока EV3 загрузится (индикатор станет зелёным)

После этого программа сможет отправлять код на EV3 и запускать его.

> **Важно**: Если EV3 не подключён к компьютеру, запуск программы на роботе будет невозможен.

# Подключение моторов EV3

Для правильной работы программы необходимо подключить моторы к следующим портам:

## Порты подключения

**Port.A** | Большой мотор | Левая нить (управление левым подвесом)
**Port.B** | Большой мотор | Правая нить (управление правым подвесом)
**Port.C** | Средний мотор | Перо (поднятие/опускание)

## Схема подключения

1. **Левый большой мотор** → подключается к порту **A**
2. **Правый большой мотор** → подключается к порту **B**
3. **Средний мотор** → подключается к порту **C**

# Основные возможности программы

## 1 Вкладка — Рисование

Позволяет создавать траекторию движения робота вручную.

Функции:

* добавление точек
* создание нескольких линий
* редактирование точек
* удаление точек
* сохранение координат

Управление:

левая кнопка мыши — добавить точку
правая кнопка мыши — удалить точку

пробел — начать новую линию

X — удалить последнюю точку

режим редактирования — перемещение точек

---

## 2 Вкладка — Изображение

Функции:

загрузка изображения
распознавание контуров
преобразование контуров в координаты
сохранение координат

# Преобразование координат

Используется преобразование координат:

y'' = X
x'' = -Y

Масштаб:

scale = 300 / 360 = 0.833333

Итоговые координаты:

x = -0.833333 * Y

y = 0.833333 * X + 280

# Кинематика робота

Положение пера определяется длинами нитей:

L1 = √((B + x)² + (H − y)²)

L2 = √((B − x)² + (H − y)²)

где

B — расстояние от центра до двигателя
H — высота подвеса
x y — координаты пера

---

# Перевод длины нити в угол двигателя

Диаметр барабана:

6.2 мм

Длина окружности:

π * 6.2 = 19.48 мм

1 мм намотки соответствует:

18.48 градусов поворота двигателя

Угол поворота:

angle_A = (Lmax − L1) * 18.48

angle_B = (Lmax − L2) * 18.48
